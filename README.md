
# SecureWatch Helpdesk

> Automated IT Help Desk & Vulnerability Management System

An IT and security help desk system extended with asset management and automatic vulnerability detection. It combines the full ticket lifecycle (creation, classification, SLA, escalation, audit trail) with a correlation engine that cross-references the asset inventory against the public vulnerability database (NVD) and automatically opens a ticket when it detects a critical risk.

---

## Tech Stack

- **Language**: Python
- **Backend**: Flask, Flask-SQLAlchemy, Flask-Login, APScheduler
- **Database**: MySQL, PyMySQL
- **Frontend**: Bootstrap (CDN)
- **Integrations**: Requests (NVD API consumption)

## Modules

- **Authentication**: registration and login with roles (user, technician, admin)
- **Tickets**: manual creation with automatic priority classification by keywords, SLA, escalation, comments, and audit trail
- **Asset inventory**: registry of equipment, servers, and software with installed version
- **Vulnerability scanning**: periodic job that queries the NVD API (National Vulnerability Database) for each registered asset
- **Automatic correlation**: if a CVE with critical or high severity (CVSS) is found for an asset, the system automatically opens a ticket and assigns it to the security queue
- **Deduplication**: prevents creating repeated tickets for the same CVE already detected on an asset

---

## Automatic Detection Flow

```
Registered asset (e.g. Apache 2.4.49)
        ↓
Periodic job queries the NVD API
        ↓
Finds a CVE with critical CVSS
        ↓
System opens an automatic ticket (priority inherited from CVSS)
        ↓
Security technician manages it like any other ticket
```

## Installation

Clone the repository:

```
git clone <repo-url>
cd securewatch-helpdesk
```

Create a virtual environment:

```
python -m venv venv
```

Activate the environment:

**Windows**
```
venv\Scripts\activate
```

**Linux / Mac**
```
source venv/bin/activate
```

Install dependencies:

```
pip install -r requirements.txt
```

---

## Configuration

Create the database by running:

```
mysql -u root -p < schema.sql
```

Set environment variables (or edit `config.py` directly):

```
DB_USER=user
DB_PASSWORD=password
DB_HOST=localhost
DB_PORT=3306
DB_NAME=securewatch_db
SECRET_KEY=your-secret-key
NVD_API_KEY=your-nvd-api-key
```

---

## Running the App

```
python app.py
```

The application will be available at:

```
http://localhost:5000
```

The vulnerability scanning job runs in the background at the interval configured in `jobs/vuln_scanner.py`.

---

## Database

Main tables: `usuarios`, `categorias`, `tickets`, `comentarios`, `auditoria`, `activos`, `vulnerabilidades_detectadas`. The last one links to `tickets` to trace which ticket was automatically generated by which CVE.
